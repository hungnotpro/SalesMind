# SalesMind OS — User Stories

## US-001
As a sales operator, I want to paste an order message so that SalesMind extracts products and quantities.

## US-002
As a sales operator, I want shorthand such as `55 bơ` resolved to a known product so that I do not retype catalog names.

## US-003
As a sales operator, I want uncertain product mappings highlighted so that I can correct them.

## US-004
As a sales operator, I want `giao trong ngày` to become a delivery task so that I do not forget same-day delivery.

## US-005
As a sales operator, I want invoice requirements extracted so that invoice work is visible in my daily tasks.

## US-006
As a sales operator, I want customer history so that repeated customers are recognized consistently.

## US-007
As a manager, I want an audit trail so that I can understand why an order/task was created.

## US-008
As an operator, I want duplicate messages to be idempotent so that the same order is not created twice.

## US-009
As an operator, I want to correct AI output so that future alias resolution can improve.

## US-010
As an administrator, I want versioned business rules so that changes are controlled and testable.
