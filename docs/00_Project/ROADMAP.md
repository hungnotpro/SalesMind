# SalesMind OS — Roadmap

## Phase 0 — Genesis
Complete product, domain, AI, architecture, API, engineering, and Codex documentation.

## Phase 1 — SM-001
Manual message ingestion → extraction → review → order/task persistence.

## Phase 2 — Knowledge
Product catalog, aliases, customer memory, correction workflow, golden dataset.

## Phase 3 — Operations
Daily dashboard, task management, reminders, order lifecycle.

## Phase 4 — Zalo Adapter
Evaluate and implement a compliant/stable message collection mechanism. Core domain must remain channel-independent.

## Phase 5 — Integrations
Calendar, accounting/MISA, inventory, invoice systems where technically and legally appropriate.

## Phase 6 — Agent Runtime
Evaluate Cloudflare Agents/Durable Objects/Queues for long-lived agent workflows and scalable deployment.

## Release Principle
Do not advance a phase because a demo works. Advance when acceptance criteria, evaluation, reliability, and operational safety are met.
