# SalesMind OS — Design System

## Principles
- operational clarity
- high information density without clutter
- predictable actions
- strong distinction between verified and AI-proposed data
- responsive desktop-first layout

## Status Semantics
Use consistent visual semantics for:
- success/completed
- pending
- warning/review
- error/blocked
- neutral/information

Do not encode meaning by color alone.

## Typography
Use a readable sans-serif hierarchy with clear labels, numeric alignment for quantities, and accessible contrast.

## Interaction
Destructive or irreversible actions require confirmation.
Review actions should show the before/after result.
