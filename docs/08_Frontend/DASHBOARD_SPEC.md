# SalesMind OS — Dashboard Specification

## Primary Views

### Today
- tasks due today
- overdue tasks
- orders received today
- orders needing review
- unresolved products

### Orders
Columns/concepts:
- order reference
- customer
- date
- status
- item count
- delivery requirement
- invoice requirement
- review state

### Tasks
Filter by status, due date, type, owner, and order.

### Customers
Search by name/phone; show verified history and recent orders.

### Products
Search canonical catalog and aliases; allow authorized alias correction.

## Review Queue
Review cards must show:
- original message excerpt
- extracted value
- proposed value
- confidence/resolution state
- evidence
- approve/correct/reject actions

## UX Principle
The dashboard should optimize for operational decisions, not AI novelty.
