# SalesMind OS — Error Codes

## Validation
- `VALIDATION_ERROR`
- `INVALID_QUANTITY`
- `INVALID_DATE`
- `INVALID_STATE_TRANSITION`

## Resolution
- `PRODUCT_UNRESOLVED`
- `PRODUCT_AMBIGUOUS`
- `CUSTOMER_UNRESOLVED`
- `CUSTOMER_AMBIGUOUS`

## Processing
- `PROCESSING_FAILED`
- `AI_PROVIDER_ERROR`
- `AI_OUTPUT_INVALID`
- `RULE_ENGINE_ERROR`

## Data
- `NOT_FOUND`
- `DUPLICATE_RESOURCE`
- `CONFLICT`

## Security
- `UNAUTHORIZED`
- `FORBIDDEN`

## Internal
- `INTERNAL_ERROR`

Messages are safe for users; detailed diagnostics belong in protected logs.
