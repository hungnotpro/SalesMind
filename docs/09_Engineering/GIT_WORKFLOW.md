# SalesMind OS — Git Workflow

## Branches
- `main`: stable integration branch.
- `feature/*`: feature implementation.
- `docs/*`: documentation work.
- `fix/*`: bug fixes.
- `refactor/*`: isolated refactors.

## Commits
Use Conventional Commits.

## Pull Requests
Every PR should explain:
- problem
- solution
- tests
- docs changed
- risks

## Review
Do not merge architectural changes without the relevant ADR/RFC.

## AI-generated changes
Codex changes must be reviewed by a human before production merge.
